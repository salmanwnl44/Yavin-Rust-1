# Hello World (sample)

Yavin's sample extension: it shows every part of the extension API working.

## Features

- **Hello World: Say Hello** greets you (the name is the `yavin-samples.hello-world.name`
  setting) and remembers the greeting in the workspace's extension state.
- A **Greetings** view in the Extensions side bar, and an **About** view in its own Activity Bar
  container.
- **Hello World: Describe Active File** in the editor's context menu for Markdown files.
- A hover on Markdown files.

## Requirements

Yavin 2 (extension API 2.0).
